# 立地評価 一次スクリーニング

地図で地点を選ぶと、次を1ページにまとめ、各項目に **確認済み／未確認** と **出典** を付けるWebアプリです(静的サイト。サーバー不要で動きます)。

- 土地の規制:区域区分・用途地域・農地転用の見込み・開発許可の見込み
- 周辺住宅との距離と、市ごとの基準
- 市の条例・ガイドラインと、必要な手続き・様式
- 注意点:住民・道路(搬入)・消防

対象外:電力の接続可否・費用・時期。

## 1. 公開する(GitHub Pages)
1. このフォルダの中身をGitHubのリポジトリに置く(`index.html` がルート)。
2. Settings → Pages → Branch を `main` / `(root)` にして Save。
3. 表示されたURLを開く。これだけで地図・周辺の建物/道路/消防署・市の基準は動きます。

## 2. 用途地域・区域区分を出す(任意だが重要)
国土交通省「不動産情報ライブラリ」のAPIを使います。ブラウザから直接呼ぶことは非推奨(キーが見える・CORS)なので、中継サーバーを1つ置きます。
1. 不動産情報ライブラリでAPI利用申請をしてキーを取得(承認に日数がかかる場合があります)。
2. Cloudflare Workers で `worker/` をデプロイ:
   ```
   cd worker
   # wrangler.toml の ALLOWED_ORIGINS を自分のPagesのURLに変更
   npx wrangler deploy
   npx wrangler secret put REINFOLIB_KEY    # キーを貼る
   ```
3. `js/config.js` の `PROXY_URL` にWorkerのURLを入れる。
   (動作確認だけなら URL の末尾に `?proxy=https://...` でも可)

未設定のあいだ、用途地域・区域区分は「未確認」と理由つきで表示されます(嘘は出しません)。

## 3. 市の基準を増やす
`data/municipalities.json` に市区町村コード(5桁)をキーに追記します。**公開されている条例・ガイドラインの原文URLを `url` に入れた項目だけ「確認済み」になります。** URLが `null` の項目は「出典URL未登録=未確認」と表示されます。

## 4. 限界(重要)
- 建物・道路・消防署・農地の手がかりは OpenStreetMap で、未登録の物があります。距離は概算です。
- 農地転用・開発許可・住民・道路搬入・消防は、地図データだけでは判定できないため常に「未確認」です。論点と確認先を示すだけです。
- 法的判断・許認可の代わりにはなりません。
